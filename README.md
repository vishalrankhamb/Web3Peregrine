# Web3Peregrine

Empowers real-time, auto-scaling, blockchain-agnostic transactions via a decentralized, smart gateway platform architecture.

With Web3Peregrine, you get a lightweight tool that stays out of your way.

**What you get**

- Empowers real-time, auto-scaling, blockchain-agnostic transactions
- via a decentralized, smart gateway
- platform architecture

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/Web3Peregrine.git`
2. `cd Web3Peregrine`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure Web3Peregrine, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
